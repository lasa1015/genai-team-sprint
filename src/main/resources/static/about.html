About the FX App

A lightweight foreign-exchange demo app for browsing rates, quoting conversions, and reviewing recorded transfers from one shared sprint build.

App name

FX App — the team's Spring Boot + MySQL + plain HTML/CSS/JS exchange app.

Built by

Amara, Bo, Chen, and Deniz — a small sprint team shipping one feature at a time.

What it ships

Live rates, pair lookup, conversion quotes, transfer history, API stats, and rate history.

Team members

  • Amara — welcome flow and about-page sprint owner
  • Bo — single-pair lookup
  • Chen — conversion calculator
  • Deniz — data and market-stat work

Features shipped

  • Latest FX rates on the welcome page
  • Single-pair lookup for the newest quoted rate
  • Conversion calculator with retail fee tiers
  • Recorded transfer history, newest first
  • Clean JSON validation and not-found errors
  • Explicit tradeable currency pairs in the database
  • Market statistics for transfers and rate freshness
  • Historical rate lookups for each currency pair
